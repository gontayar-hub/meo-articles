# meo-articles

מאמרים לאתר MEO.

## התהליך

1. אתה נותן רשימת נושאים או מילות מפתח (למשל "חול חתולים טבעי", "חול מעץ מול חול בנטוניט")
2. אני כותב את המאמרים וקובע להם תאריך פרסום, ושם אותם בריפו
3. אתה רואה אותם לפני שהם עולים ומאשר, או מבקש תיקון
4. GitHub מפרסם אותם אוטומטית באתר, כל אחד בתאריך שנקבע

## איך זה עובד בפועל

- המאמרים נשארים בדרייב כ-Google Docs. הדרייב נקרא בלבד, שום דבר לא מוזז ולא נמחק שם
- שם כל מסמך מתחיל בתאריך: `29.11 - כותרת המאמר`. זה תאריך הפרסום (שנה לפי תיקיית החודש)
- מסמך בלי תאריך בתחילת השם, וגיליונות, לא עולים לאתר
- כל יום ב-06:00 בערך (ובכל שינוי בריפו) רץ `scripts/sync.py`: קורא את תיקיות החודשים עד החודש הנוכחי, ומפרסם רק מאמרים שהתאריך שלהם היום או קודם
- מאמרים עתידיים לא נשמרים בריפו, ולכן לא נחשפים לפני הזמן
- תיקיות של חודשים קודמים נשארות באתר, תיקיות של חודשים עתידיים לא נקראות

## הגדרות חד-פעמיות

- Secret בשם `GDRIVE_KEY` עם מפתח JSON של חשבון שירות (Viewer על תיקיית הדרייב)
- Settings, Pages, Source: GitHub Actions

## הרצה ידנית

Actions, publish, Run workflow
